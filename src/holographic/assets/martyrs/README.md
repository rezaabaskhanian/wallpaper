# عکس شهدا

عکس هر شهید را اینجا بگذار با این مشخصات:

- فرمت: **WebP**
- ابعاد: مربع **۵۱۲×۵۱۲** پیکسل
- نام فایل = همان `id` در `martyrs.json` (مثلاً `shahid-01.webp`)

بعد از افزودن هر عکس، یک خط هم در نقشهٔ `PHOTOS` داخل `../../martyrs.ts` اضافه کن:

```ts
'shahid-01': require('./assets/martyrs/shahid-01.webp'),
```

> نکته: React Native نمی‌تواند مسیر عکس را داینامیک از روی رشته بسازد، پس هر عکس
> باید یک خط `require` ثابت در `martyrs.ts` داشته باشد.
