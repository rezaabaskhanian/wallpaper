# توضیح کامل صفحه‌ی هولوگرافیک (Holographic Home)

این سند همه‌چیز را درباره‌ی صفحه‌ی خانه‌ی لانچر توضیح می‌دهد: ساختار، هر فایل چه‌کاری می‌کند، و چطور بخش‌های مختلف را شخصی‌سازی کنی.

---

## ۱. صفحه چه شکلی است؟

یک صفحه‌ی خانه‌ی سبک «هولوگرافیک/DNA» شامل:

- **پس‌زمینه**: یا یک **عکس تمام‌صفحه** (اگر در `config.ts` تنظیم شود) یا **پس‌زمینه‌ی توپوگرافیک** متحرک (Skia).
- **چند حلقه‌ی دایره** (پرتره‌ی شهدا) که مثل ستون DNA به‌صورت **عمودی از بالا به پایین** می‌چرخند؛ هر حلقه شعاع/تعداد/سرعت خودش را دارد.
- **ساعت زنده + شمارش معکوس** قابل‌تنظیم بالای صفحه.
- **پنل تنظیمات** پشت دکمه‌ی چرخ‌دنده ⚙.
- **حرکت با انگشت**: کشیدن عمودی همه‌ی حلقه‌ها را می‌چرخاند (با اینرسی)، کشیدن افقی پارالاکس ملایم می‌دهد.

> همه‌ی تصاویر فعلاً placeholder هستند (گرادیان رنگی). تصاویر واقعی در `data.ts` جایگزین می‌شوند.

├── SettingsPanel.tsx           → مودال تنظیمات (چرخ‌دنده ⚙)

├── TopographicBackground.tsx   → پس‌زمینه‌ی توپوگرافیک متحرک (Skia)
├── OrbitLayer.tsx              → چند حلقه‌ی دایره + ریاضیات چرخش عمودی DNA

## ۳. هر فایل دقیقاً چه می‌کند؟

### `HolographicHome.tsx` — مرکز فرماندهی
اینجا همه‌ی مقادیر انیمیشن (Shared Values) و جسچرها تعریف می‌شوند:

- `bgProgress` → لوپ آرام پس‌زمینه (۶۰ ثانیه).
- `orbit` → چرخش **خودکار** مدار (۷۰ ثانیه برای هر دور کامل — هرچه بزرگ‌تر، کندتر).
- `manualRotation` → چرخشی که **کاربر با انگشت** اضافه می‌کند؛ روی `orbit` جمع می‌شود.
- `parallaxX / parallaxY` → جابه‌جایی ملایم لایه‌ها هنگام کشیدن.

**جسچر `pan`:**
- `onChange`: کشیدن عمودی (`changeY`) به `manualRotation` اضافه می‌شود؛ کشیدن افقی → پارالاکس.
- `onFinalize`: بعد از رها کردن، `withDecay` باعث می‌شود چرخش با **اینرسی** ادامه یابد و آرام بایستد.

سه اندازه‌ی کلیدی:
```ts
orbitRadius = min(width,height) * 0.40   // شعاع مدار
iconSize    = min(width,height) * 0.115  // اندازه‌ی دایره‌های مداری (کوچک)
heroSize    = min(width,height) * 0.34   // اندازه‌ی قهرمان (بزرگ)
```

### `OrbitLayer.tsx` — ریاضیات مدار DNA
برای هر دایره یک زاویه‌ی پایه بر اساس ترتیبش حساب می‌شود، بعد چرخش خودکار + دستی به آن اضافه می‌شود:

```ts
// هر حلقه با سرعت و جهت خودش می‌چرخد؛ کشیدن انگشت به همه اضافه می‌شود.
const spin = ring.direction * (orbit.value * ring.speedFactor + manualRotation.value);
const angle = baseAngle + spin;
const x = centerX + radius * 0.40 * Math.sin(angle) - size / 2; // X فشرده
const y = centerY - radius * Math.cos(angle)        - size / 2; // Y کامل → عمودی
const depth = (Math.sin(angle) + 1) / 2;   // ۰ = پشت، ۱ = جلو
const scale = 0.55 + depth * 0.5;          // جلوها بزرگ‌تر، پشتی‌ها کوچک‌تر
```

- `orbit.value` هر فریم در `HolographicHome` با `useFrameCallback` انباشته می‌شود (سرعت زنده).
- استفاده از `-radius * cos` باعث می‌شود سمت جلوی حلقه **از بالا به پایین** حرکت کند.
- `depth` هم اندازه، هم شفافیت و هم `zIndex` را کنترل می‌کند تا حس سه‌بعدی بدهد (پشت قهرمان کم‌رنگ، جلو پررنگ).

### `HeroCenter.tsx` — قهرمان مرکزی
پرتره‌ی وسط با یک **هاله‌ی طلایی نبض‌دار** (`pulse`) و شعار زیر آن. کمی بالاتر از مرکز قرار می‌گیرد و پارالاکس ملایم می‌گیرد.

### `Avatar.tsx`
یک دایره‌ی واحد: اگر `image` باشد عکس، وگرنه گرادیان رنگی، با یک حلقه‌ی نورانی دور آن.

### `data.ts`
- `HERO` → عنوان، شعار، رنگ و (اختیاری) عکس قهرمان.
- `ORBIT_ITEMS` → آرایه‌ی دایره‌های مداری؛ هر آیتم `id`، `label`، `colors` و `image` اختیاری دارد.

## ۴. چطور شخصی‌سازی کنم؟ (راهنمای سریع)

| می‌خواهم... | کجا | چه‌کار کنم |
|-------------|-----|-----------|
| چرخش کندتر/تندتر | `HolographicHome.tsx` | `duration` مقدار `orbit` را کم/زیاد کن (بزرگ‌تر = کندتر) |
| جهت چرخش برعکس | `OrbitLayer.tsx` | علامت `-` پشت `(rotation + manualRotation)` را عوض کن |
| دایره‌ها بزرگ‌تر/کوچک‌تر | `HolographicHome.tsx` | ضریب `iconSize` را تغییر بده |
| حلقه پهن‌تر/باریک‌تر (حس سه‌بعدی) | `OrbitLayer.tsx` | ضریب `0.40` در `x` را تغییر بده |
| حساسیت چرخش دستی | `HolographicHome.tsx` | مقدار `dragToRadians` را کم/زیاد کن |
| مدت اینرسی بعد از رها کردن | `HolographicHome.tsx` | `deceleration` در `withDecay` (نزدیک‌تر به ۱ = طولانی‌تر) |
| افزودن/حذف شهید | `data.ts` | آیتم به `ORBIT_ITEMS` اضافه/کم کن (توزیع خودکار می‌شود) |
| عکس واقعی به‌جای گرادیان | `data.ts` | `image: require('...')` را به آیتم اضافه کن |
| عکس پس‌زمینه | `config.ts` | `WALLPAPER.background = require('./assets/...')` |
| تعداد/شعاع/سرعت حلقه‌ها | `config.ts` | آرایه‌ی `RINGS` را ویرایش کن |
| تعداد حلقه‌ی نمایشی، سرعت، ساعت، تاریخ شمارش معکوس | داخل خود اپ | از پنل **تنظیمات ⚙** به‌صورت زنده |
| مدت هر دور کامل چرخش | `config.ts` | `BASE_TURN_SECONDS` (بزرگ‌تر = کندتر) |

## ۵. اجرا

```bash
# نصب وابستگی‌ها (یک‌بار)
npm install

# اجرا روی اندروید
npx react-native run-android
```

وابستگی‌های کلیدی: `react-native-reanimated`, `react-native-gesture-handler`, `@shopify/react-native-skia`, `react-native-safe-area-context`.

> نکته: `GestureHandlerRootView` باید ریشه‌ی اپ را بپوشاند (در `App.tsx` انجام شده) وگرنه جسچرها کار نمی‌کنند.
