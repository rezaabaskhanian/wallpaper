# نقشه‌راه — ایده‌های نسخه‌های بعدی

فیچرهایی که فعلاً پیاده‌سازی نشده‌اند ولی برای نسخه‌های بعدی در نظر گرفته شده‌اند.

---

## افکت‌های هوش‌مصنوعی روی عکس پس‌زمینه (کارتونی، ونگوگ، سینمایی، ...)

ایده: کاربر یک عکس اضافه می‌کند، و ما آن را با یک سرویس هوش‌مصنوعی به سبک‌های مختلف (کارتونی، نقاشی ونگوگ، سینمایی و ...) تبدیل می‌کنیم.

**بررسی شد:** DeepSeek API برای این کار مناسب نیست — مدل‌های DeepSeek (deepseek-chat، deepseek-reasoner، حتی DeepSeek-VL) متنی/استدلالی‌اند و فقط عکس را *می‌فهمند*، قابلیت تولید یا ویرایش تصویر (image-to-image) ندارند.

**پیشنهاد:** استفاده از [Replicate](https://replicate.com) — پلتفرمی که صدها مدل آماده (اکثراً مبتنی بر Stable Diffusion/SDXL) را به‌صورت API در اختیار می‌گذارد، پرداخت بر اساس ثانیه‌ی GPU مصرف‌شده (هر عکس معمولاً بین چند سنت تا حدود ۵۰ سنت).

**نکات معماری برای پیاده‌سازی:**
- کلید API نباید در اپ RN باشد؛ باید یک اندپوینت جدید در بک‌اند Go اضافه شود که عکس را می‌گیرد، به Replicate می‌فرستد، و لینک خروجی را برمی‌گرداند.
- تولید عکس چند ثانیه تا حدود نیم دقیقه طول می‌کشد → نیاز به polling یا webhook.
- چون هزینه‌بر است، باید یک محدودیت مصرف (مثلاً چند بار در روز، یا فقط برای کاربر پرمیوم) روی این قابلیت گذاشته شود تا سوءاستفاده نشود.
- مدل‌های کاندید: img2img مبتنی بر SDXL با پرامپت سبک (مثلاً «van gogh style painting»)، مدل‌های اختصاصی cartoonify/anime (مثل AnimeGANv2)، یا `instruct-pix2pix` برای دستور متنی مستقیم.

**وضعیت:** فقط ایده — هنوز شروع نشده. برای شروع باید یک اکانت Replicate ساخته و API token گرفته شود.
